The costume line remains generic because its menu shadow has a second field value that the shorter `self.costume = "..."` form does not encode. There are **32** such costume lines in this project, plus **7** similarly verbose sound menu lines.

## Mario Bros Commercial Remake: movement and a malformed-looking hat

```diff
-when broadcast message1 at 123,563 {
-  gotoXY -999, 9;
-  setSize 150;
+on message message1 at 123,563 {
+  self.position = (-999, 9);
+  self.size = 150;
   repeat 2 {
-    costume "1";
+    self.costume = "1";
     repeat 3 {
-      changeX 6;
+      self.x += 6;
     }
```

Another script still begins this way:

```fractch
script at 477,233 {
  event.whenbroadcastreceived(BROADCAST_OPTION: broadcast("TURTLE", "broadcastMsgId-turtle"));
  self.position = (-136, 9);
  repeat 3 {
    self.costume = "5";
    repeat 2 { self.x += -8; }
  }
}
```

The SB3 hat field says `TURTLE`, while the project broadcast table stores `turtle` under `broadcastMsgId-turtle`. The source generator correctly retains both values, but the resulting code obscures the event flow. Eight hats in this project have this issue.

## Exact follow-up opportunities

| Priority | Observed source | Potential source | Static condition for a safe round trip |
| --- | --- | --- | --- |
| 1 | `looks.switchcostumeto(COSTUME: shadow looks.costume(field COSTUME: ["part 1//1","id"]))` | `self.costume = "part 1//1" menuId "id";` | One `looks_costume` shadow, a two-element `COSTUME` field, no other data |
| 1 | `script { event.whenbroadcastreceived(BROADCAST_OPTION: broadcast("TURTLE", "id")); ... }` | `on message "TURTLE" id "id" { ... }` | A top-level broadcast hat with an explicit field ID that differs from name lookup |
| 2 | `self.x += -8;` | `self.x -= 8;` | `motion_changexby` with a negative numeric literal; retain the primitive's exact value |
| 2 | `temperature ++ "°" ++ temp_unit` | `` `${temperature}°${temp_unit}` `` | A left-associated join chain beginning with a reporter; parsing must not add a leading empty-string join block |
| 3 | `json_get(...) ++ ""` | `asText(json_get(...))` | A join whose right input is exactly an empty string; keep the other join orientation generic |
| 3 | `fetch.get(URL: url)` and `skyhigh173JSON.json_get(item: key, json: data)` | `fetch.get(url)` and `skyhigh173JSON.get(data, key)` | Only for registered extension opcodes with known input names, order, and unchanged mutation |
| 3 | `script at 372,1869 { currentMonth() ++ ...; }` | `orphan at 372,1869: currentMonth() ++ ...;` | A disconnected top-level reporter with no `next` block; preserve its workspace coordinates |

These are presentation changes to exact block shapes. The projects also have nested error handling and repeated animation loops. Flattening those branches, hoisting repeated blocks, or replacing loops with one assignment would change the Scratch block tree and may change runtime scheduling, so they need a separate semantic transformation rather than source-generation sugar.
